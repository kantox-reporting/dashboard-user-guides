📋What is the K2 DH Report?

The K2 DH Report is the transaction-level Dynamic Hedging report for the K2 programme. It mirrors the structure of the standard DH Report but operates on a separate, dedicated set of hedging entries and coverage rules specific to the K2 programme configuration.

💡 Key Value: Review and audit every individual K2 hedge entry — its amounts, rates, status, and performance — with the same level of detail as the standard programme, but scoped exclusively to K2 activity.

Key Benefits

  • ✓
    K2-Scoped Entries — all data is filtered exclusively to K2 programme entries; no cross-contamination with K1 data
  • ✓
    Entry-Level Detail — creation dates, value dates, notional, execution rates, and current status for every K2 hedge entry
  • ✓
    Performance Attribution — DH Performance, Pricing P&L, and Forward Points at the individual entry level
  • ✓
    Coverage & Bucket Monitoring — see how K2 entries fill defined hedging buckets across the coverage horizon

🔑The K2 Programme

The K2 programme is a separate Dynamic Hedging configuration with its own exposure profile, coverage rules, and hedging parameters, distinct from the primary K1 programme. Key differences to be aware of:

  • •
    Separate entry pool — K2 entries are created independently from K1 entries and have their own reference numbering
  • •
    Own bucket structure — K2 may have a different set of hedging buckets or tenor bands compared to K1
  • •
    Independent coverage rules — coverage ratios and rebalancing triggers are defined separately for K2
  • •
    Consolidated view available — for a cross-programme view, use the standard DH Analytics Dashboard which can be configured to show both K1 and K2 exposure together
💡 K1 vs K2: If you are unsure which programme an entry belongs to, check the entry reference prefix or the programme field in the entries table. This report will only ever show K2 entries.

📝K2 Entries & Performance

The entries table and performance metrics in the K2 DH Report follow the same structure as the standard DH Report. Each K2 entry shows:

FieldDescription
Entry ReferenceUnique K2 entry identifier
Creation DateWhen the K2 entry was submitted to the programme
Value DateSettlement / maturity date of this K2 entry
Currency PairFX pair for this entry
Notional / Normalised AmountOriginal and reporting-currency-converted amounts
Hedge RateExecution rate for this K2 entry
DH PerformanceValue created vs. the unhedged benchmark at time of creation
Pricing P&LP&L from market movements since creation
Forward PointsCost-of-carry component of the hedge rate
StatusCurrent state (open / closed)
⚠️ Performance on open entries: DH Performance and Pricing P&L on open K2 entries are indicative and will continue to change until the entry reaches its value date and is cash-settled.

🔄Data Refresh

  • 📅
    K2 data refreshes once per business day alongside the main programme data
  • 💱
    Normalisation rates and performance metrics are recalculated at each refresh
  • 📊
    New K2 entries created today will appear after the next daily refresh
