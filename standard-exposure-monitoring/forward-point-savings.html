💰 What is Forward Point Savings?

Forward Point Savings (FPS) captures the value gained from when a hedge actually executes relative to when the entry was first created — comparing the forward points available at each moment and translating the difference into a monetary saving.

💡 Key value: Use this page to see where FPS is concentrated — by currency pair, over time — and drill down to the exact rates and points behind any individual entry.
🔍 Top KPI ribbon: The six tiles across the top of this page are the same on every page of this report — see the Exposure Overview guide for what they mean.

📋 Forward Point Savings at Entry Detail

The table at the bottom of the page shows the full FPS calculation for every individual entry:

ColumnDescription
Entry Reference / Order ReferenceThe entry and its linked hedge order
Hedge StatusThe linked order's current status
Dir CCY Pair / Value DateThe entry's currency pair and settlement date
Normalized AmountThe entry's amount converted to the display currency
Spot / Forward (Entry creation)The spot and forward rates in effect when the entry was first created
Entry points (basis)The forward points implied by those two rates at entry creation — forward rate minus spot rate, in basis points
Spot / Forward (Execution)The spot and forward rates in effect when the order actually executed
Execution points (basis)The same forward-points calculation, but at execution time
Points ΔThe difference between entry points and execution points, direction-adjusted for buy/sell — the number of forward points gained or lost by the timing of execution
Forward Point SavingsThe points difference converted into a monetary value
Fwd Point Savings normalizedThe same value, converted to the display currency
⚠️ Note: Forward Point Savings figures are colour-coded — red when negative, blue when meaningfully positive.
