🎯 What is PnL Selection?

This page lets you focus on one PnL component at a time and see how it's trended over time, while a table below always shows every component side by side for full context.

🔍 Top KPI ribbon: The six tiles across the top of this page are the same on every page of this report — see the Exposure Overview guide for what they mean.

🎛️ The PnL Picker

The row of buttons labeled "PnL Selection" lets you choose which PnL component the evolution chart below focuses on:

Option Group Basis
Pricing PnLPricing + Spot PnLRealized
Spot Realized PnLRealized
Spot Unrealized PnLUnrealized
Forward Points PnL (Realized)Forward Points ImpactRealized
Forward Points PnL (Unrealized)Unrealized

Only one option is active at a time, and it drives the evolution chart directly below the picker.

📈 PnL Evolution Chart

A combo chart showing whichever PnL component you picked above, by month, stacked and colored by status (e.g. Monitoring, Canceled, Closed - Executed, Expired, Open (CR), Expired (CR), Closed - netted).

💡 Tip: Switch the picker to compare how each PnL component trends over time — for example, whether unrealized spot movement or forward-points impact is driving recent changes.

📊 Total PnL by Status

A bar chart showing Total PnL — all five components combined — broken down by status. Unlike the evolution chart, this one always shows the full total regardless of what's selected in the picker above.

📋 Detail Table

One row per currency pair and direction, showing every PnL component side by side — this table is always fully expanded and doesn't change with the picker above:

Column Description
Currency Pair / DirectionThe currency pair and buy/sell direction for this row
Original Amount / Counter AmountThe entry amount and its counter-side equivalent, shown at the direction level
Currency / Counter CurrencyThe base and quote currencies
Normalized AmountThe unnetted entry amount converted to the display currency
Pricing / Spot Realized / Spot Unrealized / Fwd Realized / Fwd Unrealized PnLEach of the five PnL components — see the Entry Detailed Analysis guide for what each one means
Total PnLSum of all five components for this row
