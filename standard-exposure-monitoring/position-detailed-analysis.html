📊 What is Position Detailed Analysis?

One row per position — the netted view. Where Exposure Overview gives you the aggregate picture and Entry Detailed Analysis shows individual trades, this page sits in between: every position you hold, netted, with its own amount, PnL, and status all in one table.

💡 Key value: Use this page to find a specific position and see its full picture at a glance, then right-click it to drill into the entries behind it.
🔍 Top KPI ribbon: The six tiles across the top of this page are the same on every page of this report — see the Exposure Overview guide for what they mean.

🔧 Filters

Click the filter icon in the top-right corner to open a filter panel over the page. It offers:

  • •
    Create Date and Value Date — restrict to positions opened or settling in a date range
  • •
    Entity Group and Company Name — restrict to a client or group of related clients
  • •
    Dir CCY Pair — restrict to one or more directional currency pairs
  • •
    Standardized Status and Split Status — restrict to specific position or split states
  • •
    Order Status and Execution Reason — restrict by the linked hedge order's status or execution trigger
  • •
    Position Reference and Order Reference — jump straight to a known reference

📋 Position Level Table (Netted Exposure)

The main table on this page — one row per position reference:

Column Description
Position ReferenceUnique identifier for the position
Created DateWhen the position was opened
Dir CCY PairThe position's directional currency pair
DirectionBuy or sell
Amount / CurrencyThe position's netted notional and its currency
Counter Amount / Counter CurrencyThe equivalent netted amount and currency on the counter side, using the position's weighted average rate
Value DateSettlement date of the position
Standardized StatusThe position's current lifecycle status (e.g. Monitoring, Closed - Executed, Expired)
Split StatusWhether any part of this position's amount is held back from hedging by a Cancellation Rate setting (fully managed, or partly held back)
Order Reference / Order StatusThe hedge order linked to this position, and that order's own status
Execution ReasonWhy the underlying order executed (e.g. trigger hit, manual execution)
Normalized AmountThe position's netted amount converted to the display currency
Pricing / Spot Realized / Spot Unrealized / Fwd Realized / Fwd Unrealized / Total PnLThe five PnL components for this position — see the Entry Detailed Analysis guide for what each one means
⚠️ Note: Only positions with a normalized amount are shown, and blank/empty position references are excluded from this table.

🔎 Getting to Entry-Level Detail

Right-click any row in the position table and choose Drill through → Entry Detailed Analysis to see every individual entry behind that position — the exact trades that make it up, netted or not.

💡 Tip: Everything you had filtered here (client, date range, currency pair, status, etc.) carries over automatically to the entry-level page. Use the back arrow there to return to this table.
